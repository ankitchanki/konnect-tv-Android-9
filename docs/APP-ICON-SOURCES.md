# Remote shortcut icons

JioHotstar uses the current JioHotstar icon retrieved from its official [Google Play listing](https://play.google.com/store/apps/details?id=in.startv.hotstar) on 21 October 2026. The icon is used unmodified to identify the app shortcut. It remains the property of its owner; no endorsement is implied.

Cloudstream uses its unmodified [upstream launcher icon](https://github.com/recloudstream/cloudstream/blob/master/app/src/main/res/mipmap-xxxhdpi/ic_launcher.png). Cloudstream source is available at https://github.com/recloudstream/cloudstream (GPL-3.0). The icon identifies the external app shortcut; it is not app code linked into Konnect TV Plus.

YouTube's play badge is drawn in the UI. Other installed app icons in Apps/Glowlauncher are obtained from the TV's package manager.
